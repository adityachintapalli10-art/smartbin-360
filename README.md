# SmartBin 360

A lightweight static web app for monitoring smart waste bins, route optimization, AI demand forecasting, alerts, and IoT simulator controls.

## Run locally

```bash
python server.py
```

Then open http://localhost:3000

## Files

- `index.html` – complete app UI and JavaScript logic
- `server.py` – Python static file server
- `package.json` – npm-compatible start scripts
